🎸 Music Theory Tool

What is this tool for?
This tool is designed to help you understand music theory on the guitar by showing scales, diatonic chords, chord tones, practical guitar voicings, and intervals. The diatonic chord generator is a learning and reference tool, not a rulebook. A song or progression does not have to stay entirely within one key or mode; musicians regularly use borrowed, chromatic, secondary-dominant, and otherwise non-diatonic chords. This tool simply helps you see which chords naturally belong to a particular key or mode and how those chords can be built.
